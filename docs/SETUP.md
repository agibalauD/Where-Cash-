# Установка и самостоятельная настройка WhereCash

## Что потребуется

- Mac с macOS 14 или новее;
- Xcode 26.2 или совместимая версия;
- интернет для курса НБ РБ и Telegram;
- Telegram-аккаунт, если нужен бот.

Платный Apple Developer Account не требуется для запуска приложения из исходников на собственном Mac. Developer ID и notarization нужны только для обычного распространения готовой сборки другим пользователям.

## Получение исходников и запуск

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/agibalauD/Where-Cash-.git Where-cash
   cd Where-cash
   ```

2. Откройте `WhereCash.xcodeproj` в Xcode.
3. Выберите схему `WhereCash` и назначение `My Mac`.
4. Нажмите Run.
5. Найдите значок банкноты в строке меню macOS. WhereCash специально не отображается в Dock.

Если Xcode запросит команду разработчика, достаточно выбрать личную команду Apple ID в разделе Signing & Capabilities. Платная подписка для локального запуска не нужна.

## Локальная сборка из Terminal

```bash
/Applications/Xcode.app/Contents/Developer/usr/bin/xcodebuild \
  -project WhereCash.xcodeproj \
  -scheme WhereCash \
  -configuration Debug \
  -derivedDataPath /tmp/WhereCashDerivedData \
  CODE_SIGNING_ALLOWED=NO build
```

Сборка появится в `/tmp/WhereCashDerivedData/Build/Products/Debug/WhereCash.app`. Она предназначена для локального тестирования и не подписана Developer ID.

## Первоначальная настройка приложения

1. Откройте WhereCash левым кликом по значку в строке меню.
2. Нажмите шестерёнку.
3. Выберите, показывать одну валюту или BYN и USD одновременно.
4. При необходимости задайте сумму и валюту месячного лимита.
5. Создайте одну или несколько целей накоплений и отметьте цель, которую нужно показывать и пополнять.
6. При желании включите запуск после входа в macOS.

Чтобы начать статистику заново без удаления старых данных, используйте в настройках раздел «Период статистики». Старые расходы останутся в истории как архив, а накопления сохранятся.

Курс USD/BYN загружается из открытого API НБ РБ. Отдельный API-ключ для курса не требуется.

## Создание собственного Telegram-бота

1. Откройте официальный чат [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`.
3. Задайте отображаемое имя и уникальное имя пользователя, заканчивающееся на `bot`.
4. Скопируйте выданный Bot API token. Не публикуйте его и не отправляйте другим людям.
5. В WhereCash откройте настройки, раздел Telegram, вставьте токен и нажмите «Подключить бота».
6. После проверки токена приложение покажет одноразовую команду вида `/start A1B2C3D4`.
7. Отправьте эту команду созданному боту со своего Telegram-аккаунта.
8. После сообщения об успешной привязке используйте кнопки «Добавить» и «Статистика».

WhereCash обслуживает только один привязанный аккаунт. Бот работает, пока приложение запущено на Mac; отдельный сервер не требуется.

## Где хранятся секреты и данные

- Bot API token хранится зашифрованным в macOS Keychain и доступен только на разблокированном текущем Mac. Токены, сохранённые ранними версиями WhereCash, автоматически переводятся в этот режим при первом запуске обновления.
- Telegram ID владельца и служебная позиция обновлений хранятся в локальных настройках macOS.
- Расходы, накопления и цели находятся в локальном контейнере SwiftData.
- Эти данные не входят в Git-репозиторий и не синхронизируются автоматически.
- Каталог `dist`, базы, `.env`, сертификаты и ключи исключены через `.gitignore`.

Если токен случайно попал в сообщение, скриншот или Git, откройте `@BotFather`, отзовите старый токен и создайте новый. Удаления строки только из последнего коммита недостаточно, потому что секрет может остаться в истории Git.

## Отключение Telegram

В настройках WhereCash нажмите «Отключить бота» и подтвердите действие. Приложение удалит токен из Keychain и сбросит привязку владельца. После этого можно подключить другого бота.

## Проверка установки

После настройки рекомендуется проверить:

1. Добавление расхода из приложения.
2. Добавление расхода через Telegram: сумма → валюта → категория.
3. Команду `/stats` или кнопку «Статистика».
4. Создание цели и категорию «Накопления».
5. Сохранение истории после перезапуска приложения.

## Частые проблемы

- Значка нет в Dock — это штатное поведение; приложение находится в строке меню.
- Telegram не отвечает — убедитесь, что WhereCash запущен и Mac подключён к интернету.
- Токен не принимается — выпустите новый токен через `@BotFather` и вставьте его без пробелов.
- Бот не принимает сообщения другого пользователя — это предусмотренная защита одного владельца.
- Нет пересчёта USD/BYN — дождитесь загрузки курса НБ РБ или проверьте интернет.
